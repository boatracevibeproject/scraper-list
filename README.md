# BVP Scraper List

> [!IMPORTANT]
> このリポジトリはアーカイブ済みです。各場の公式サイトから選手コメントなどを取得する機能は [scraper-stadiums](https://github.com/boatracevibeproject/scraper-stadiums) に統合しました。
>
> This repository is archived. Stadium-specific scrapers have been consolidated into [scraper-stadiums](https://github.com/boatracevibeproject/scraper-stadiums).

## 現行のリポジトリ | Current repositories

| Repository | Overview | Packagist |
|:---|:---|:---|
| [scraper](https://github.com/boatracevibeproject/scraper) | ボートレース公式サイトから出走表・直前情報・オッズ・結果を取得 | [bvp/scraper](https://packagist.org/packages/bvp/scraper) |
| [scraper-stadiums](https://github.com/boatracevibeproject/scraper-stadiums) | 各場の公式サイトにしか無い情報（選手コメントなど）を取得 | [bvp/scraper-stadiums](https://packagist.org/packages/bvp/scraper-stadiums) |
